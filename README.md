# Mini Payment-Tracking System

Система учёта оплат и мониторинга задолженностей для учебного центра с REST API на **FastAPI** (интерактивная документация Swagger доступна по адресу `/api`), асинхронной базой данных **SQLite** на базе **SQLAlchemy 2.0** и Telegram-ботом на **aiogram 3.x**.

---

## Возможности системы

- **Управление студентами (CRUD)**: создание, просмотр, обновление и удаление данных студентов (ФИО, номер телефона, группа, сумма ежемесячного платежа).
- **Регистрация оплат**: фиксация платежей с привязкой к студенту, дате и сумме, а также просмотр истории платежей по каждому студенту.
- **Расчёт должников за месяц**: автоматический подсчёт студентов, оплативших меньше установленной ежемесячной суммы за выбранный период (`GET /debtors?month=YYYY-MM`).
- **Telegram-бот**:
  - `/start` — приветствие и список доступных команд.
  - `/debt` — список должников за текущий месяц с указанием остатка долга и внесенных средств.
  - `/pay <student_id> <amount>` — быстрая регистрация платежа с мгновенным выводом обновленного баланса.
  - `/help` — подробная справка по работе с ботом.
- **Swagger UI**: интерактивная документация OpenAPI доступна по маршруту `/api`.

## Быстрый старт (Запуск с нуля)

### 1. Клонирование репозитория
```bash
git clone https://github.com/RahmatillaXudoyberdiyev/Test-Assignment-for-Ecomdev.git
cd Test-Assignment-for-Ecomdev
```

### 2. Создание и активация виртуального окружения
На Windows (PowerShell):
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

На Linux / macOS:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Скопируйте шаблон `.env.example` в `.env`:
```bash
cp .env.example .env
```
*(В Windows PowerShell: `Copy-Item .env.example .env`)*

Откройте файл `.env` и укажите ваш токен Telegram-бота:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
DATABASE_URL=sqlite+aiosqlite:///./education_center.db
API_HOST=127.0.0.1
API_PORT=8000
```

> **Примечание по базе данных и тестовым данным:**
> - База данных SQLite (`education_center.db`) создаётся автоматически при первом запуске приложения, дополнительных установок СУБД (PostgreSQL / MySQL) не требуется.
> - **Автоматическое наполнение тестовыми данными (Auto-seed):** при первом старте на чистой базе данных система автоматически предзаполняет базу тестовыми студентами с различными статусами оплат (должники и оплатившие в полном объёме). Это позволяет сразу протестировать команды `/debt`, `/pay` и Swagger API без ручного ввода. Данная функция авто-наполнения предназначена исключительно для этапа тестирования/оценки задания и будет удалена в продакшн-версии (production).

## Запуск проекта

### Вариант 1: Одновременный запуск API и Telegram-бота (Рекомендуемый)
```bash
python run.py
```
Команда запускает FastAPI-сервер на `http://127.0.0.1:8000` и асинхронный поллинг Telegram-бота.

### Вариант 2: Раздельный запуск компонентов

**Запуск REST API:**
```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
Документация Swagger будет доступна по адресу: [http://127.0.0.1:8000/api](http://127.0.0.1:8000/api).

**Запуск Telegram-бота:**
```bash
python -m bot.main
```

## Документация API

После запуска сервера Swagger UI открывается по адресу:
- **Swagger UI**: `http://127.0.0.1:8000/api`
- **ReDoc**: `http://127.0.0.1:8000/redoc`

### Основные эндпоинты:
| Метод | Маршрут | Описание |
| :--- | :--- | :--- |
| `POST` | `/students` | Создать нового студента |
| `GET` | `/students` | Получить список студентов (с пагинацией и фильтрацией по группе) |
| `GET` | `/students/{student_id}` | Получить информацию о конкретном студенте |
| `PUT` | `/students/{student_id}` | Обновить данные студента |
| `DELETE`| `/students/{student_id}` | Удалить студента и связанные с ним платежи |
| `POST` | `/payments` | Зарегистрировать платеж за обучение |
| `GET` | `/payments/student/{student_id}` | Получить историю всех платежей студента |
| `GET` | `/debtors?month=YYYY-MM` | Список должников за указанный месяц (по умолчанию — текущий месяц) |

## Что можно улучшить при наличии дополнительного времени (3–5 пунктов)

1. **Миграция с SQLite на PostgreSQL**:
   - Переход на PostgreSQL с пулом соединений (например, `asyncpg`) и использование **Alembic** для версионирования схемы базы данных и безопасных миграций при масштабировании.
2. **Интерактивный UI в боте (Inline-клавиатуры и FSM)**:
   - Замена текстовой команды `/pay <student_id> <amount>` на пошаговый мастер с Inline-кнопками: выбор группы -> выбор студента из выпадающего списка -> ввод суммы платежа, что исключит ошибки ручного ввода ID.
3. **Rule-based система уведомлений и напоминаний**:
   - Автоматическая отправка напоминаний о приближении срока оплаты (например, за 3 дня до конца расчетного периода) студентам или администраторам через фоновые задачи (Celery / APScheduler / ARQ).
4. **Ролевая модель доступа (RBAC) и JWT-аутентификация**:
   - Защита административных эндпоинтов API с помощью OAuth2 / JWT-токенов, разделение прав доступа (бухгалтер, администратор филиала, преподаватель).
5. **Мультиязычность и локализация (i18n)**:
   - Расширение модуля локализации через `Babel` / `gettext` с возможностью выбора языка (`/lang` — русский, узбекский, английский) с сохранением предпочтений пользователя в профиле.
